# DSL2 网站待确认事项

这些问题在现有方案中没有最终答案。开发应把它们配置化或显示为“待公布”，不得自行创造赛事规则。

## 上线前必须确认

1. 十周赛程的实际开始日期和结束日期是什么？
2. 每个常规赛比赛日使用 2v6 还是 3v5，轮换由谁、在何时公布？
3. 两名或多人总积分相同时，名次和段位如何处理？
4. 黄金、白银的排名分界线分别是什么？
5. 黄金资格边界发生同分时，是否全部获得 KK 战队联赛资格？
6. 积分榜按比赛日、每周还是其他频率更新？
7. 漏录、错录、改判和补录由谁提出、谁复核、何时截止？
8. DSL2 正式使用的地图文件和版本是什么？新方案目录已有 c1.1 和 5.6 两份候选文件，更新说明只明确 5.6 对应 3v5；c1.1 的适用模式、两份文件是否已经冻结为正式版，以及发布时间仍需确认。旧站 4.47 与线上原型 1.70 也不能自动沿用。
9. 网站应公开哪个主办方联系方式或社区入口？
10. 新站的中文正式名称、英文或缩写副标题是否保持当前方案写法？

## 季后赛开始前必须确认

1. KK 战队联赛四名队长、队名、选人方法和阵容限制。
2. 战队联赛单个比赛日的对阵、局数、计分和胜负判定方式。
3. 韩服 8R 每个比赛日的局数、计分、晋级方式，以及如何产生赛季冠亚季军。
4. 季后赛是否公开详细对局结果，还是只公开队伍或个人最终名次。
5. 常规赛铂金及以上奖励的实际分配方法。
6. 三项众筹的实际收款、费用扣除和未达到目标时的奖金调整方法。

## 可在第一版之后决定

1. 是否公开本周新增积分。
2. 是否公开名次变化。
3. 是否公开对局积分与赛事工作积分的构成。
4. 是否在积分榜标记季后赛资格。
5. 是否建立 DSL1 历史档案，以及历史数据开放到什么粒度。
6. 是否保留赞助者姓名、金额和头像；每位赞助者需重新确认公开意愿。
7. 是否增加直播、录像或解说链接。
