# DSL2 规范化赛事数据

本目录保存第二届 DSL 的本地管理数据，不会被复制到公开网站的 `src` 或 `public` 目录。

## 文件职责

- `dsl2-master.json`：第二届 DSL 的规范化总数据文件，是后续统计、分析与导出的统一真理来源。它包含计分规则、主名称规则、所有比赛日、所有对局、原始 ID、主名称、种族、退出事件、单盘积分、每日积分变动及完整累计积分榜。
- `full-standings.csv`：供赛事管理者直接使用 Excel 或文本编辑器查看的唯一完整积分榜，包含全部选手，以及对局积分、赛事工作积分、参赛盘数、胜负、掉线、地主/富农/贫农胜场与胜率、身份盘数和工作人员天数。

## 上游原始数据

- `match-data/YYYYMMDD/YYYYMMDD.json`：每个比赛日的原始统计数据。
- `match-data/same_name.csv`：昵称归并的唯一规则来源。每行第一个名称是主名称，同一行后续名称才会被归并到该主名称；生成器不会推断文件之外的任何别名关系。

如需修正比赛或昵称，应修改上述上游文件，然后运行：

```powershell
pnpm run build:match-reports
```

不要直接手工修改本目录的两个最新版生成文件。`pnpm run check:match-reports` 会检查它们、公开赛报和公开积分榜是否仍与原始数据一致。

公开积分榜展示完整积分榜的全部选手，不设人数上限。所有选手公开名次、主名称、积分、段位，前五名额外公开总场数和总胜率；其余统计明细仍仅保留在本目录。

段位配置统一保存在 `src/data/standing-tiers.json`：王者第 1 名，星耀第 2–5 名，钻石第 6–10 名，铂金第 11–20 名，黄金第 21–30 名，白银第 31–40 名，青铜第 41 名及以后。总数据的 `scoringRules.publicStandingLimit: null` 表示不设公开人数上限，所有人员的 `publiclyListed` 均为 `true`。

## 掉线核算

掉线规则配置保存在 `src/data/disconnect-policy.json`。生成器从首个比赛日起，按比赛日期、录像文件名时间排序，先通过 `same_name.csv` 归并昵称，再按「选手主名称 + 赛区 + 周一日期」累计掉线次数。每周按 UTC+8 的周一至周日计算。

- 每人每周在 KK、韩服各有一次豁免：首次掉线该盘 0 分，第二次该盘扣 15 分，并禁止参加该赛区当周余下比赛；另一赛区不受影响。
- 2026 年 9 月 4 日的掉线事件全部排除：该盘 0 分，不计次数、不消耗豁免、不扣分、不触发禁赛；其他选手和工作人员正常计分。
- 掉线者仍计一次参赛及失利，其余选手按原始赛果结算。`disconnects` 保留实际掉线事件总数，`countedDisconnects` 排除平台故障；另列每周豁免次数、平台排除次数与扣分合计。
- 总数据的 `matchDays[].disconnectEvents` 保存逐次处理结果、当周序号、积分和禁赛截止日期；逐盘选手数据的 `disconnect` 保存对应判定。公开赛报也展示当日掉线核算说明。
- 如后续记录出现选手在同周同赛区禁赛期间继续出场，生成器会报错并要求核实原始记录，避免未经裁定直接发布积分。
