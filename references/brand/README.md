# DSL 正式赛事徽章资料

本目录保存第二届 DSL 网站采用的正式赛事徽章源文件，供后续网站、直播和赛事物料制作使用。

- `dsl-official-logo-selected-original.png`：最终选定的原始生成稿，保留原始灰白棋盘背景，作为视觉源档归档。
- `dsl-official-logo-transparent-master.png`：从选定原稿中移除棋盘背景后的透明主文件；徽章造型、颜色和构图保持不变。

网站实际加载的是 `public/assets/` 下的轻量版本：

- `dsl-official-logo.webp`：192×192，供页头与页面内容使用。
- `dsl-official-logo-512.webp`：512×512，供站点清单与社交分享使用。
- `dsl-official-logo-64.png`：64×64，供浏览器标签页使用。

旧版 `dsl-three-races-suits.webp` 与 `dsl-three-races-suits-512.webp` 暂时保留，不再被页面引用，必要时可用于回溯。
